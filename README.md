# Task Management Application

A full-stack Task Management Application built using HTML, CSS, JavaScript, Node.js, Express.js, MongoDB and JWT authentication.

## Features

- User registration
- User login
- JWT authentication
- Secure password hashing
- User-specific tasks
- Create tasks
- Edit tasks
- Delete tasks
- Complete and undo tasks
- Task search
- Task priority
- Task categories
- Task status
- Task due dates
- Overdue task detection
- Task statistics dashboard
- Responsive design
- Mobile and tablet support

## Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js
- REST API

### Database

- MongoDB
- Mongoose

### Authentication

- bcryptjs
- JSON Web Token (JWT)
